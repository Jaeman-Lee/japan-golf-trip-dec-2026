## 우선순위

1. **다카마쓰 가와라마치 4박 + 야시마 54홀 직접예약**이 첫 후보다. 골프장 공식 플랜에 사흘 모두 2인 단독이 명시돼 있다. 시내 더블 조식, 공항·골프장 전 구간 택시, 동행 1인 오른손 대여채 배송, 온천과 항구 교통까지 넣은 **2인 소계 2,038,109원, 1인 평균 1,019,055원**. 예산 잔여 361,891원에서 실제 항공 위탁 추가금·미포함 식사·여행보험·국내 공항 이동·쇼핑을 지출한다. 택시는 미터 추정, 항공은 2인 검색 표시가이며 부킹 완료 금액은 아니다.
2. **마트·쇼핑과 관광 하루를 더 쓰면 4박 36홀**. 12/21·22만 라운드하고 23일 대회와 택시 왕복을 빼면 **2인 1,808,460원, 1인 평균 904,230원**. 3일 대여료를 그대로 잡아도 591,540원이 남는다. 23일 점심은 직접 마련한다. 
3. **패키지는 다카마쓰 시내 3박 54홀**이 가격을 문의할 만하다. 2인 할증을 더한 공시 시작가로 계산하면 **1인 105만 원부터**다. 날짜 확정가·남성 풀세트·수하물·미포함 식사를 더했을 때에만 직접예약과 비교할 수 있다. 벳푸는 운전 없이 온천과 바다를 즐기는 3박 36홀 대안이다.

### 골프백과 240만 원 예산

- 한 사람은 개인 클럽을 가져간다. 에어서울 일본 노선 위탁은 정규·할인 15kg, 특가 0kg이며 골프백도 무게에 포함한다. 출국·귀국 각각 실제 수하물 포함 결제액을 비교한다. 남성 한 세트도 가져갈 때 **왕복 추가비**가 ¥13,740(약 116,007원)보다 낮으면 두 사람 모두 지참하는 편이 싸다. [무료 위탁 및 특수 수하물](https://flyairseoul.com/CW/ko/destinations.do) · [사전 구매 요금](https://flyairseoul.com/CW/ko/noticeContent.do?pageNo=0&seq=7246)
- 예를 들어 아내의 위탁이 특가 0kg이고, 25kg를 양쪽 모두 사전 구매하면 한국 출발 12만 원 + 일본 출발 ¥12,000 = 약 221,316원이다. 출발 48시간 전, 현지통화 기준 예시다. 다른 일행의 짐·결제통화·실제 운임에 따라 달라진다. 이 경우 54홀 안은 2,259,425원으로 올라가고, 두 사람 식사·보험·쇼핑 등으로 140,575원이 남는다. **36홀 안은 같은 수하물 시나리오에서도 370,224원이 남는다.**
- 네 번의 호텔 조식과 23일 골프 점심을 계산에 포함했다. 20~22일 점심과 20~23일 저녁, 24일 귀국 후 식비는 별도다. 항공+위탁을 제외한 54홀 소계는 1,309,509원. 나머지 식사·쇼핑·보험·국내 교통 몫으로 예를 들어 25만 원을 남기려면 **2인 왕복 항공+모든 위탁 합계가 840,491원 이하**여야 한다. 이는 실제 시세가 아닌 구매 판단선이다.
- 12/21과 22의 점심은 골프장 플랜에 미포함이다. 마트 반입식은 골프장 반입 규정이 확인되지 않아 숙소 취식으로 계획했다.
